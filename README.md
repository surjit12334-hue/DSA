## Overview

This repository contains implementations of common data structures and algorithms used in computer science. It serves as a learning resource and reference for understanding fundamental concepts.

## Data Structures

- Arrays
- Linked Lists
- Stacks
- Queues
- Trees (Binary Tree, BST, AVL)
- Graphs
- Hash Tables
- Heaps

## Algorithms

- Sorting (Bubble, Selection, Insertion, Merge, Quick)
- Searching (Linear, Binary)
- Graph Algorithms (BFS, DFS, Dijkstra)
- Dynamic Programming
- Greedy Algorithms
- Recursion

## Usage

Browse the directory structure to find specific implementations. Each data structure and algorithm includes its own README with explanations and examples.
